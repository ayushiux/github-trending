# Sumeet — GitHub Repo Relevance Profile

Score how relevant a **trending GitHub repository** is to Sumeet (0–100). Judge what the repo
actually *is and does*, not just keyword presence.

## Role & Background
- Builder/orchestrator at Microsoft (Mountain View). Ships production automation daily —
  browser agents, supervisors, multi-step pipelines, LLM tooling.
- Wants to find genuinely useful, currently-hot repos in the agent / coding / AI world, and
  cool products people are building with agents and "vibe coding."

## Score HIGH (80–100) — core interests
- **Agents & agent frameworks**: autonomous agents, multi-agent orchestration, agent runtimes
  (LangGraph, CrewAI, AutoGen, ADK, OpenAI Agents SDK, swarm/graph orchestration).
- **MCP (Model Context Protocol)**: MCP servers, clients, tooling, registries.
- **Coding agents & AI dev tools**: Claude Code, Codex, Cursor, Windsurf, Aider, Cline, Copilot-style
  tools, autonomous SWE agents, code-review/PR agents.
- **Agent evals & benchmarks**: eval harnesses, agent benchmarks, tracing/observability for agents
  (Langfuse-style), test/verification for LLM systems.
- **"Skills"**: Claude skills, agent skills, skill libraries/marketplaces, tool/plugin ecosystems.
- **Creative productivity tools built on LLMs**: apps/tools that use Claude/GPT/Codex/agents to build
  real things — "vibe coding" app builders, generative dev tools, workflow automation.
- **LLM infra & serving**: inference engines (vLLM, SGLang, llama.cpp), local model runners (Ollama,
  LM Studio), fine-tuning, quantization, RAG frameworks, vector DBs.
- **Open models**: Llama, Mistral, Qwen, DeepSeek, Gemma, Nemotron and similar releases.

## Score MEDIUM (40–65)
- General ML/DL libraries, data engineering, MLOps without a clear agent/dev-tool angle.
- Startup/dev productivity tools tangential to the above.
- Web3/crypto only when it meaningfully intersects with AI agents.

## Score LOW (3–20)
- Generic web templates, boilerplate, awesome-lists with no substance.
- Pure front-end/UI component libraries with no AI angle.
- Games, crypto/DeFi without AI, unrelated systems/kernel projects.
- Study-notes / interview-prep / "list of X" repos.

## Calibration
- No minimum floor — off-domain repos score 3–10, not 15–25.
- 90–100 is reserved for repos squarely in agents / MCP / coding-agents / agent-evals / skills that
  a builder would want to try this week.
- Use the full 0–100 range with non-round numbers.
